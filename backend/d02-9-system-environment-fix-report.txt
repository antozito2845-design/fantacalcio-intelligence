D02.9 - SYSTEM STATUS RUNTIME ENVIRONMENT FIX REPORT
Generated: 2026-08-24 Europe/Rome

ROOT CAUSE
The Flyway V1 seed inserts system_information.environment as the static value
"development". SystemStatusService previously read that persisted seed value and
returned it from GET /api/v1/system/status, even when Spring was running with the
prod profile. The database value therefore described migration-time seed data,
not the current runtime environment.

IMPLEMENTED SOLUTION
SystemStatusService now receives Spring Environment and derives the response field
"environment" from the runtime profiles. The database query still supplies the
unchanged application name and version, but no longer reads the seeded environment
column. Status remains "UP" and checkedAt remains generated with OffsetDateTime.now().

Profile resolution is deterministic:
- If prod is among the active profiles, return "production".
- Otherwise, if dev is among the active profiles, return "development".
- Otherwise, if another profile is active, return the first active profile name.
- If no profile is active, return Spring's first default profile (normally "default").

WHY V1 WAS NOT MODIFIED
V1 is an already-applied Flyway migration. Editing it would invalidate migration
checksums and violate migration immutability. Setting its seed to "production" (or
adding a migration that always writes "production") would also be semantically
wrong because the same migration history is used in dev and test. The fix belongs
at runtime, where Spring knows the active environment.

RUNTIME BEHAVIOR
- dev: active profile "dev" -> API environment "development".
- prod: active profile "prod" -> API environment "production".
- default/test: with no active profile, the API reports Spring's default profile,
  normally "default". If an explicit "test" profile is active, the generic profile
  rule reports "test". This does not invent a dev/prod classification.
- In mixed profiles, prod takes precedence over dev to avoid misreporting a production
  runtime; dev takes precedence over other custom profiles.
